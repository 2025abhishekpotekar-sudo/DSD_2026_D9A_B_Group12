# Presentation Guidelines

Cover:
1. Problem statement, objectives and requirements.
2. Proposed architecture and distinctive features.
3. FSM/state table and Logisim implementation, where applicable.
4. Verilog RTL architecture and design decisions.
5. Testbench, test cases and simulation results.
6. FPGA board, implementation flow and hardware demonstration.
7. Expected-versus-observed results, challenges and corrections.
8. Conclusion, limitations and future improvements.
9. Individual contribution of each group member.

All four members should be ready to answer technical questions.
